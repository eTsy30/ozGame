# Коробочный переполох — MVP 0.1

Небольшая браузерная аркада на React + TypeScript + PixiJS 8. Игрок сортирует коробки по шести шкафам; каждый шкаф содержит 12 пронумерованных ячеек.

## Запуск

Требуется Node.js 20.19+ (или совместимая актуальная версия) и npm.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Управление

1. Нажми «Начать смену».
2. Смотри на код коробки на руках у персонажа и в строке «Текущий адрес».
3. Код `04 / 08` означает: шкаф №4, ячейка №8.
4. Нажми нужную ячейку. За попадание начисляется 1 копейка.
5. Неправильная ячейка или истёкшее время отнимают одну жизнь.
6. После каждых пяти успешных доставок скорость увеличивается.
7. После трёх ошибок смена заканчивается.

## Текущий объём MVP

- Шесть шкафов на игровом поле.
- Сетка 4 × 3 в каждом шкафу.
- Случайные адреса из 72 ячеек.
- Таймер на каждую коробку.
- Ускорение каждые пять попаданий.
- Три жизни.
- Анимация броска и падения коробки.
- Счёт в копейках и рекорд в `localStorage`.
- Мышь и pointer/touch-события.
- Пауза и перезапуск.

## Архитектурные решения

- React отвечает за оболочку, счётчик, кнопки, оверлеи и состояние экранов.
- `SortingGame` — независимый игровой объект, который управляет PixiJS Application, сценой, интерактивными ячейками, таймером и анимациями.
- Игровой цикл работает через `app.ticker`; React не обновляется на каждом кадре.
- Текущий персонаж нарисован примитивами PixiJS как временная заглушка. Следующий этап — заменить его и коробку на спрайты.

## Принятые игровые допущения

- Код коробки — это `номер шкафа / номер ячейки`.
- Нумерация ячеек идёт слева направо, сверху вниз: 01–12.
- За верную доставку начисляется одна копейка.
- Неверный адрес и тайм-аут одинаково отнимают жизнь.
- Начальное время — 3,5 секунды; каждые пять доставок таймер сокращается на 0,28 секунды, минимум до 0,82 секунды.
